# 🏥 TFM Health Chatbot
Sistema conversacional basado en agentes IA para el ámbito de la salud.

## 🚀 Cómo ejecutar

1. Iniciar Ollama:
.\start_ollama.bat

2. Iniciar la API:
python api.py

3. Abrir el navegador en http://localhost:5000

## ⚠️ Disclaimer
Este sistema es únicamente informativo y no reemplaza el criterio médico profesional.
